Step 01 · action table

One hand becomes three tables

A converter reads raw hand histories and writes every hand, player and action as clean rows.

Two kinds of input

Hands arrive as plain text logs or as an operator’s JSON export. One converter turns both into the same clean format.

Three tables

Each hand is split three ways: one row per hand, one row per player, one row per action. Every later step reads these rows.

One action row, zoomed in

Each row stores the price. He pays 3 bb into a 9.5 bb pot, so a call must win 32% of the time.

Money check

Every chip put into a hand must come out as winnings, returned bets or rake. This sum is checked on every hand.
